# GIMFA Digital — Sistema de identificación estudiantil QR

MVP con registro manual y Excel, fotografías privadas, carné público por token aleatorio, panel administrativo y revocación de manillas. Frontend estático en GitHub Pages, PostgreSQL/Auth/Storage y Edge Function en Supabase.

**Instalación:** lee `GUIA_INSTALACION.md`.

**Privacidad:** la consulta por QR no requiere login y muestra datos personales de menores. No activar con datos reales sin autorización específica y revisión de riesgos.
